# نوفا ديجيتال — متجر رقمي تجريبي

واجهة متجر عربية باتجاه RTL مصممة باستخدام HTML وCSS وJavaScript فقط.

## تشغيل الموقع
1. فك ضغط الملف إن حمّلته كـ ZIP.
2. افتح `index.html` في متصفح حديث.
3. لا يحتاج المشروع إلى تثبيت حزم أو تشغيل خادم للتجربة الأساسية.

## الموجود في النسخة
- صفحة رئيسية متجاوبة مع شعار وهوية بصرية.
- منتجات تجريبية وأسعار بالجنيه المصري.
- بحث وتصنيفات وترتيب حسب السعر.
- سلة مشتريات مع تغيير الكمية والحذف، وتُحفظ محليًا في المتصفح.
- نموذج Checkout ببيانات العميل وطريقة الدفع المفضلة.
- شاشة تأكيد ورقم طلب تجريبي.
- أسئلة شائعة ونموذج اشتراك بريدي توضيحي.

## مهم قبل الإطلاق التجاري
هذه **واجهة Frontend تجريبية** وليست نظام تجارة إلكترونية متكاملًا للإنتاج. الطلبات تُحفظ في `localStorage` على الجهاز الحالي فقط، ولا تُرسل إلى صاحب المتجر أو قاعدة بيانات. لا توجد معالجة دفع فعلية، ولا إرسال آلي للمنتجات الرقمية أو رسائل بريد. كذلك بيانات المنتجات والأسعار والتقييمات الواردة أمثلة توضيحية وليست عروضًا حقيقية.

لتشغيل متجر فعلي، يلزم على الأقل:
- Backend وقاعدة بيانات لتسجيل الطلبات والمستخدمين والمنتجات والتحقق من الأسعار والكميات على الخادم.
- بوابة دفع معتمدة، مع إنشاء جلسات الدفع والتحقق من إشعارات الدفع على الخادم وعدم حفظ بيانات البطاقة في الواجهة.
- نظام تسليم رقمي آمن يسلّم الملفات أو الأكواد بعد التأكد من نجاح الدفع.
- إعدادات حقيقية للشحن الرقمي/الشروط/الخصوصية وسياسة الاسترجاع وبيانات الدعم.
- استبدال بريد `support@novadigital.example` ببريد الدعم الحقيقي، وتحديث بيانات الكتالوج.

## التخصيص
- بيانات المنتجات: مصفوفة `PRODUCTS` في `app.js`.
- الألوان والتجاوب والتصميم: `styles.css`.
- هيكل الصفحة والنصوص: `index.html`.
